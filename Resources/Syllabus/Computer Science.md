# Computer Science (SL/HL)
Group 4 (Sciences) · new guide, first teaching 2025, first assessment 2027 · SL 150 h, HL 240 h
Aliases: Computer Science, Comp Sci, CompSci, CS HL, CS SL
Assessment details below are a summary in our words and unverified: check paper formats, the programming language the school uses (Python or Java) and marks with the teacher.

## How it's structured
Two themes taught together: A Concepts of computer science, and B Computational thinking and problem-solving (with programming in Python or Java). HL goes further in each topic and adds extra content (marked (HL)).
Assessment (outline): Paper 1 on concepts (short answers and extended responses, with a case study released in advance at HL), Paper 2 on computational thinking and programming (reading, tracing and writing code), and an internal assessment: a computational solution to a real problem for a client or themselves, with planning, design, development and evaluation.

## Theme A · Concepts of computer science
- A1 Computer fundamentals: CPU components (ALU, CU, registers, cache), the fetch–decode–execute cycle, primary and secondary memory, GPUs vs CPUs, binary and hexadecimal, data representation (integers, characters, colours, sound), logic gates and truth tables (AND, OR, NOT, NAND, NOR, XOR), Boolean expressions, operating systems (scheduling, memory management, interrupts), (HL) pipelining and multi-core, compression
- A2 Networks: types (LAN, WAN, PAN, VPN), topologies, protocols and the TCP/IP model layers, packet switching, IP addressing, DNS, wired vs wireless, network security (firewalls, encryption, symmetric and asymmetric keys, digital certificates, threats and countermeasures)
- A3 Databases: relational databases, tables, primary and foreign keys, normalization (1NF, 2NF, 3NF), entity–relationship diagrams, SQL queries (SELECT, WHERE, JOIN, GROUP BY, INSERT, UPDATE, DELETE), transactions and ACID, (HL) views, data warehouses, big data
- A4 Machine learning: supervised, unsupervised and reinforcement learning, training and test data, classification and regression, linear regression, k-nearest neighbours, decision trees, clustering (k-means), neural networks (layers, weights, activation), overfitting, bias in data, ethics of AI, (HL) deep learning and genetic algorithms

## Theme B · Computational thinking and problem-solving
- B1 Computational thinking: abstraction, decomposition, pattern recognition, algorithmic design, flowcharts and pseudocode, tracing algorithms with trace tables
- B2 Programming: variables, data types, operators, selection, iteration, functions and parameters, scope, strings, arrays and lists, 2D arrays, file input and output, exceptions, debugging and testing (normal, boundary, erroneous data), searching (linear, binary) and sorting (bubble, selection, insertion), efficiency and Big O (O(1), O(log n), O(n), O(n log n), O(n²))
- B3 Object-oriented programming: classes and objects, attributes and methods, constructors, encapsulation, inheritance, polymorphism, aggregation and composition, UML class diagrams, (HL) abstract classes and interfaces, design patterns
- B4 Abstract data types (HL focus): stacks, queues, linked lists, binary trees and traversals (pre-, in-, post-order), binary search trees, hash tables, recursion, (HL) graphs and their traversal

## How to quiz it
- Concepts: "Define…" [1–2], "Describe…" [2–4], "Explain…" [4–6], "Evaluate…" with trade-offs (cost, speed, security, ethics).
- Tracing: give a short pseudocode or Python/Java snippet and ask for the output, a completed trace table, or the bug.
- Writing code: "Construct an algorithm/method that…" [4–8], marked on correct logic (loop bounds, conditions, return values), not exact syntax.
- Data: give a small table and ask for an SQL query, a normalization step, or a binary/hex conversion.
- Common slips to probe: off-by-one loop bounds, = vs ==, integer division, confusing a class with an object, stack (LIFO) vs queue (FIFO), binary search on unsorted data, Big O of nested loops, mixing up encryption and hashing.
