# Joe handoff docs

Joe is developed in separate chats, one per area. Start each chat with:

> Read `docs/handoff/00-common.md` and `docs/handoff/<area file>` in `~/Desktop/Code/shhh`, then help me with: …

| File | Area |
|---|---|
| `00-common.md` | Everyone: project, build/install/commit rules, preferences, architecture, data, test commands |
| `01-voice-input.md` | Keys, recording, speech recognition, live words, dictation, "make it a prompt" |
| `02-voice-output.md` | Alba and Mandarin voices, speaking replies, memory |
| `03-assistant-core.md` | Claude sessions, system prompt, model routing, cost, OpenRouter/custom endpoints, ChatGPT plan |
| `04-notch-and-card.md` | Notch band, hover overview widgets, answer card, pill, pen, toasts |
| `05-dashboard-ui.md` | Dashboard pages, themes and design system |
| `06-onboarding-setup-release.md` | Onboarding, Claude setup, model downloads, DMG |
| `07-study.md` | Syllabus packs, whiteboard, marking, MYP, points calculator |
| `08-school-data-calendar.md` | Daybook, timetable, calendar links, ManageBac, briefing |
| `09-alarms-routines-automations.md` | Alarms, wake-up challenge, routines, iPhone bridge |
| `10-integrations.md` | Spotify, messages, notes, Mac control, slides/maths/PDF tools |
| `11-business-and-roadmap.md` | Beta status, feedback, roadmap, business notes |

When an area's chat changes something, it updates its file (and `00-common.md` if a shared rule changes) in the same commit.
